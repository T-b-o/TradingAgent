# Technology Change Request

Use this template before adding, installing, replacing, configuring, or using
any technology that is not already explicitly approved by TradingAgent project
policy.

Do not implement the change until the user explicitly approves it.

---

## 1. Problem Being Solved

Describe the concrete problem or requirement.

## 2. Proposed Technology

Name the package, framework, library, runtime, service, provider, platform, SDK,
middleware, database, API, or other technology.

## 3. Why the Current Approved Stack Is Not Enough

Explain why the approved stack cannot reasonably solve the problem.

## 4. Alternatives Considered

List at least one alternative, including an option that stays within the current
approved stack where possible.

## 5. Why This Technology Is Preferred

Explain the technical reason for preferring it over the alternatives.

## 6. Cost / Licensing Impact

State whether it is free, open source, paid, usage-metered, trial-based, or has
licensing constraints.

## 7. $0/R0 Impact

Explain whether it preserves the project's $0/R0-first rule.

## 8. Security Impact

Describe data exposure, credentials, attack surface, supply-chain risk, network
access, authentication, authorization, and privacy implications.

## 9. Architecture / System-Flow Impact

Explain how it changes boundaries, dependencies, runtime flow, deployment flow,
or responsibilities between projects.

## 10. Runtime / Deployment Impact

Describe any new process, runtime, service, configuration, port, background
worker, hosting requirement, or deployment requirement.

## 11. Maintenance / Complexity Impact

Explain long-term ownership, versioning, upgrade, testing, debugging, and
operational complexity.

## 12. New Dependencies / Packages / Services Introduced

List every new dependency, package, SDK, service, or external endpoint.

## 13. Existing Architectural Decision Changed?

State whether this changes or replaces an existing documented decision.

## 14. Recommendation

Recommend approve, reject, or defer, with a brief reason.

## 15. Approval Question

Do you approve adding this technology to the TradingAgent project?
