# Coding Skills

Technical skills are created only when we reach the relevant development phase.

Do not create a large collection of unused skills.

Each skill must:

- focus on a modern technology or important engineering practice
- be concise
- support R0/local operation
- explain practical runtime behaviour
- include debugging guidance
- include testing guidance
- avoid obsolete patterns
- avoid unnecessary paid dependencies
- follow `CodingSkillAgent/TECHNOLOGY-POLICY.md` before introducing any new
  technology, dependency, service, provider, runtime, package, or framework

Examples that will be created later:

- ASP.NET Core debugging
- Chrome DevTools
- Blazor architecture
- Blazor/API communication
- Ollama tool calling
- Agent orchestration
- Testing
- Security
- Observability

Trading strategy skills are separate and will only be created after the user
provides the real strategy.
